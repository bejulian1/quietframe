# Changelog

## 0.1.0

- First public release for Minecraft 26.3, Fabric Loader 0.19.5 and Java 25 on Vulkan.
- Added unfocused, minimized and AFK render caps with hover and input wake.
- Added optional minimized render suspension with periodic offscreen Vulkan submission for fence retirement.
- Added OpenAL listener attenuation, an optional capture-safe status badge, a toggle keybind and in-game configuration commands.
- Added startup conflict detection for Dynamic FPS and FPS Reducer.
- Added the client benchmark observer, live RTX 2080 results and release artwork.
