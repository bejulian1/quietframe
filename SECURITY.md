# Security policy

Security fixes target the latest published QuietFrame release and the main development branch.

Use GitHub private vulnerability reporting. Include the affected versions, conditions required, potential impact and steps to reproduce. If private reporting is unavailable, request a private channel through the issue tracker and keep technical details private until a channel is available. [Report a vulnerability](https://github.com/bejulian1/quietframe/security/advisories/new) · [Request a private channel](https://github.com/bejulian1/quietframe/issues)

Coordinate disclosure with the maintainer so users can receive a fix and upgrade instructions. Use the issue forms for ordinary crashes, rendering defects and performance regressions. [Issue forms](https://github.com/bejulian1/quietframe/issues/new/choose)
