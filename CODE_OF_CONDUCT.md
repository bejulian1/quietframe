# Code of conduct

Treat contributors with respect in issues, pull requests and other QuietFrame project spaces. Welcome different backgrounds and experience levels. Give feedback about the work, make room for disagreement and respect others' privacy.

Harassment, threats, discrimination, personal attacks, unwanted sexual attention and sharing private information without consent are unacceptable.

Report incidents privately to the maintainer. If you need a private contact channel, request one in an issue and share details through that channel. The maintainer will handle reports discreetly and may remove content or restrict participation based on the conduct. [Contact the maintainer](https://github.com/bejulian1/quietframe/issues)
